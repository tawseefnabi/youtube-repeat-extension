# Privacy Policy — YouTube Repeat

**Last updated:** October 14, 2025

YouTube Repeat is a browser extension that adds a repeat control on YouTube watch pages.

## Data collected

The extension **does not** collect, sell, or transmit personal data to the developer or third-party analytics servers.

## Data stored locally

- **Loop on/off preference** — stored with `chrome.storage.sync` so your choice can sync across Chrome profiles/devices signed into the same Google account.
- This is the only persisted setting.

## Permissions

- **`storage`** — save your repeat on/off preference.
- **`*://*.youtube.com/*`** — inject the repeat button and apply loop behavior only on YouTube pages.
